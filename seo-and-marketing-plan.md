## 1. Audit summary — what was found and fixed

The site had already been through one SEO pass (see `marketing/social-2026-07-02/seo-audit-2026-07-02.md`) — the blog canonical bug, missing `robots.txt`/`sitemap.xml`, and the LocalBusiness `geo`/`sameAs`/reviews gaps from that audit were **already fixed** in the current code. This pass covered what was still open:

### Fixed in this pass
| Area | Fix | Files |
|---|---|---|
| Social previews | Added `og:image:width/height/alt` and switched `og:image` from the flat logo to `assets/hero-poster.jpg` (a real 1600×900 photo of finished work) — logos underperform lifestyle/product photos in FB/IG/WhatsApp link previews | `index.html`, `blog.html` |
| Twitter/X Cards | Added `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image` — previously **completely missing site-wide** | `index.html`, `blog.html`, legal pages (`summary` card) |
| Meta description | Homepage description was 182 chars (truncates in Google's SERP snippet at ~155–160); trimmed to 131 chars and rewritten to foreground "בפריסה ארצית" (nationwide), the highest-intent phrase from the brief that wasn't in the meta description before | `index.html` |
| Schema.org type | `LocalBusiness` → `["HomeAndConstructionBusiness", "LocalBusiness"]` (more specific type Google prefers for this vertical); `image` now points at the hero photo instead of the logo | `index.html` |

| Blog post `og:type` | Per-post pages were serving generic `website` type; now switches to `article` once a `?post=` slug is detected | `blog.html` |

| Meta Pixel | No Facebook/Instagram Pixel exists yet. Added a **commented-out, ready-to-activate placeholder** in `index.html` right below the GA4 consent-mode block, wired to the same Privacy Law Amendment 13 consent pattern — just needs a real Pixel ID from Meta Events Manager | `index.html` |
| Sitemap freshness | Bumped `lastmod` to 2026-07-24 on every URL actually touched this pass | `sitemap.xml` |

### Confirmed already correct (no action needed)
- `robots.txt` and `sitemap.xml` both exist, are valid, and correctly exclude `/admin.html`, `/login.html`, `/thankyou.html`.
- `thankyou.html` already has `<meta name="robots" content="noindex, nofollow">` — correct for a post-form thank-you page.
- Every page has exactly one `<h1>` (including the blog SPA, which demotes its generic hero `<h1>` to a `<p>` once a post loads so the article's own title is the page's only H1).
- Heading hierarchy (H1→H2→H3) on the homepage is clean and semantic throughout services, FAQ, and about sections.
- All static `<img>` tags already carry descriptive Hebrew `alt` text (logo, gallery badges, footer).
- `og:locale` is `he_IL` site-wide; `lang="he" dir="rtl"` is correct on every page.
- FAQPage and LocalBusiness JSON-LD (both validated as parseable JSON) with `aggregateRating`, 6 real `review` entries, `geo`, and populated `sameAs` (Google Business Profile, Facebook, Instagram) were already in place.

### Known limitation — not fixable from this codebase
The 7 blog posts' `BlogPosting` schema (headline, description, image, `datePublished`) is generated by the third-party **Soro** embed (`app.trysoro.com`), not by this repo's code. `author`, `publisher`, and `dateModified` fields are still missing from that schema and can only be added from Soro's own dashboard/settings — flag this to Soro support or check their platform's blog-schema config.

### Recommended next steps (outside code)
1. **Submit `sitemap.xml` in Google Search Console** and request indexing for the homepage + all 7 blog posts.
2. **Verify/claim the Google Business Profile** tied to the `g.page/r/CRSEpD2_CFoDEBI` link already in the schema and reviews CTA — confirm categories include "Flooring contractor" / "Marble contractor."
3. **Create a Meta Pixel** in Meta Events Manager, then uncomment and fill in the placeholder in `index.html`.
4. Run the homepage through **PageSpeed Insights** (mobile) to get real CrUX field data — the prior audit flagged a possible preloader-related FCP delay that headless rendering can't confirm reliably.

## 3. Five blog post ideas

Chosen to close real gaps against the 7 posts already published (terrazzo, natural stone timing, marble scratches, sealer, stained marble, crystal polish, old floor renewal) — not to duplicate them.

1. **"פוליש קריסטל מול פוליש שעווה: מדריך השוואה מלא"** — a dedicated head-to-head comparison post targeting the exact phrase from the brief; the existing crystal-polish post is a general how-to, not a comparison, so this captures a different search intent.
2. **"מדריך לאחר שיפוץ: איך שומרים על הריצוף החדש בחודש הראשון"** — post-renovation tile/floor care, directly requested in the brief; a natural link target from every service page for clients mid-renovation.
3. **"בטון מוחלק ובומנייט: מדריך חידוש לחצר, מרפסת וכניסה"** — closes the content gap the last audit flagged (בומנייט/בטון מוחלק have zero blog coverage despite being homepage service cards); video scripts for this topic already exist in `marketing/social-2026-07-12-batch2-fix/`, so this post can embed/reuse that footage.
4. **"כמה עולה ליטוש שיש? מדריך מחירים ומה משפיע על העלות"** — no existing post addresses pricing at all; this is the single highest commercial-intent query type for the whole category and a strong lead-form CTA anchor.
5. **"קרצוף והחלפת רובה בקרמיקה: מתי צריך ואיך זה עובד"** — the only listed service (מס' 9 בגריד השירותים) with no matching article; low competition, easy win.

## 4. Five Facebook & Instagram Reel / post ideas

The asset library (`assets/generated/`) already has before/after reels for all 5 gallery projects plus a myth-busters, science-of-stone, and testimonial-showcase reel — these ideas build on what's *not* covered yet, leaning into the differentiation angle from prior competitor research: **Uri as a named, personally-accountable craftsman**, not a faceless service broker.

1. **"10 שניות" swipe-reveal challenge** — ultra-short before/after using a hard swipe-wipe transition synced to trending audio; optimized for Reels/Stories completion rate rather than the longer explainer-style reels already produced.
2. **"תכירו את אורי" — סרטון היכרות אישי** — Uri talking straight to camera about 30 years in the trade; personal-brand content the competitor research flagged as a real gap (both competitors read as generic service-page content, not personal/story-driven).
3. **"רגע החשיפה" — real customer reaction filmed live** — capture an actual client's unscripted reaction the moment the drop-cloth/tape comes off after crystal polish; authentic reaction content outperforms staged before/after on watch-time.
4. **Educational carousel: "5 סימנים שהשיש שלכם זקוק לליטוש"** — static/carousel post (not video) for feed variety; each slide one warning sign (עמימות, שריטות, כתמים, שקיעה, נקבוביות), last slide is the CTA.
5. **Split-screen "3 בעיות ריצוף נפוצות + פתרון"** — one 30-second reel, three quick problem/solution cuts (שריטות בשיש / כתם שמן על גרניט / רובה מתפוררת), each resolved in ~8 seconds — a format built for saves/shares as a reference clip, distinct from the single-project reels already made.
